## Возможности
- Авторизация и управление пользователями
- Управление счетами и картами
- Проведение и история транзакций
- Избранные платежи
- Уведомления
- Роли/администрирование

## Архитектура
- **Контроллеры (`src/controller/`)** — бизнес‑логика и взаимодействие с UI
- **Модели (`src/models/`)** — доменные сущности (пользователь, счёт, карта, транзакция и т.д.)
- **Хранилище (`src/storage/`)** — абстракции доступа к данным
- **Утилиты (`src/utils/`)** — исключения и вспомогательные функции
- **Входная точка (`src/main.cpp`)**

## Требования
- Компилятор C++17 (gcc/clang/MSVC)
- Qt 6.10+ (SDK, Qt Creator — по желанию)
- qmake6 и make (для сборки из CLI)

## Сборка и запуск
### Qt Creator (рекомендуется)
1. Откройте файл `Bank.pro`
2. Выберите профиль сборки (Debug/Release)
3. Нажмите Build/Run

### qmake (CLI)
```bash
# в каталоге kursovaya/
qmake6 Bank.pro
make -j
# запуск бинарника через Qt Creator или из папки сборки
```

> Примечание: точное имя исполняемого файла зависит от конфигурации проекта и окружения.
